# Тихая форма — демонстрационный проект
Четыре страницы: index.html, services.html, portfolio.html, contacts.html. Галерея из четырёх иллюстраций, переходы к направлениям и меню.

Исходники: HTML/CSS и assets/ в этой папке. Общие элементы: ../shared/base.css, ../shared/ui.js и favicon.svg. Для отдельного переноса сохранять соседнюю shared/ и относительные пути; готовый переносимый вариант находится в portfolio-dist/ вместе с shared/.

Запуск из корня пакета: `python scripts/build.py`, `python -m http.server 8765 --bind 127.0.0.1`; адрес: http://127.0.0.1:8765/portfolio-dist/furniture/ .
Никаких реальных контактов, заявок, цен, аналитики или сторонних медиа. Трудозатраты отдельно по этому сайту не измерялись: создан в общем пакете.
