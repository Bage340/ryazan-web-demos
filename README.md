# Три демо-сайта и витрина
Оригинальные статические примеры для портфолио. Компании вымышлены; реальные заявки, контакты, платежи и сбор данных отсутствуют.

## Локальный запуск
Требуется Python 3.10+; npm и сборочные зависимости не нужны.
```powershell
python scripts/build.py
python scripts/validate.py
python -m http.server 8765 --bind 127.0.0.1
```
Открыть http://127.0.0.1:8765/portfolio-dist/ . Для просмотра исходников: /portfolio-src/ и /demo-ventilation/, /demo-furniture/, /demo-autoservice/.

## Состав
- `demo-ventilation/`: технический лендинг, FAQ и демо-обращение.
- `demo-furniture/`: главная, услуги, галерея, контакты.
- `demo-autoservice/`: шиномонтаж, фильтр шести услуг, мобильная демо-запись.
- `portfolio-src/`: исходник витрины.
- `shared/`: общие доступные элементы, локальный CSS/JS и favicon.
- `portfolio-dist/`: только готовые HTML/CSS/JS/SVG, отдельный артефакт публикации.
- `scripts/`: упаковка, статический QA, браузерные сценарии и узко ограниченный помощник GitHub.
- `QA.md`, `DEPLOY_LOG.md`, `PORTFOLIO_LINKS.md`: фактические результаты.

Два прежних проекта показаны только внешними ссылками; см. `PRIOR_WORK.md`. Скрытие блока при договорных ограничениях: `python scripts/build.py --without-prior-work`. Для постоянного отключения в CI также добавить этот флаг в workflow; обычная сборка возвращает блок.

Содержимое вложений, закрытые планы поиска, токены, браузерные профили и локальные журналы не публикуются.
